# CityCommand AI — Simple Chrome Run

This folder gives you a Chrome-first demo version of the CityCommand AI project.

## Fastest way

1. Open the `web-demo` folder.
2. Double-click `index.html`.
3. It opens directly in Chrome or your default browser.
4. Click **Run AI Pipeline** or go to **Signal Intake** and inject a new report.

No backend server, Expo, Android emulator, Python venv, or database is required for this demo.

## Windows shortcut

Double-click `open-in-chrome.bat`.

## What works in the browser

- Live dashboard
- Manual signal intake
- AI pipeline simulation
- Incident queue
- AI analysis with evidence and confidence
- Resource allocation
- Agent trace / explainable AI
- Simulation scenarios
- Recovery / false alarm rollback
- Notification audit
- API preview

## Important

This is not a full backend replacement. It is a clean browser demo so you can show the project features directly in Chrome.
